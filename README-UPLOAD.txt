راهنمای نصب از آیفون
======================

این بسته نسخه نهایی و بر پایه همان index.html فعلی شماست.

1) فایل ZIP را در Files باز کنید تا پوشه ساخته شود.
2) وارد پوشه شوید و همه محتویات داخل آن را در ریشه مخزن GitHub بارگذاری کنید.
3) index.html قبلی را Replace کنید و پوشه‌ها/فایل‌های جدید را اضافه کنید.
4) خود فایل ZIP را در GitHub آپلود نکنید.
5) فایل مخفی .pages.yml در آیفون ممکن است دیده نشود؛ داخل ZIP وجود دارد. هنگام آپلود مطمئن شوید منتقل شده است.
6) بعد از Commit و انتشار GitHub Pages، برای مدیریت محتوا به https://app.pagescms.org بروید، با GitHub وارد شوید و مخزن MajidNamaki/majidnamaki را انتخاب کنید.

- .pages.yml
- .nojekyll
- content/site.json
- media/hero-majid.jpg
- assets/
- admin/
